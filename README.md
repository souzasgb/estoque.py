# 📦 Sistema de Controle de Estoque (Inventory Control System)

A simple, terminal-based inventory management application written in Python. This system allows users to track current inventory levels, register new items, update quantities, manage positions, and monitor products using an interactive menu-driven interface.

---

## 🚀 Features

The system features an interactive text menu with the following capabilities:

1. **Consult current inventory** (`1`) — Displays all products currently in stock along with their quantities.
2. **Consult initial inventory** (`2`) — Displays the original baseline inventory stored at program startup[cite: 1].
3. **Register new product** (`3`) — Appends a new product and its quantity to the end of the stock list[cite: 1].
4. **Insert product at a specific position** (`4`) — Inserts a product at a custom index within the stock list[cite: 1].
5. **Update product quantity** (`5`) — Searches for a product by name and updates its stock amount[cite: 1].
6. **Remove product** (`6`) — Deletes a specific product from inventory by name[cite: 1].
7. **Remove the last item** (`7`) — Pops and removes the final item from the stock list[cite: 1].
8. **Locate product and position** (`8`) — Searches for a specific product name and outputs its index position[cite: 1].
9. **Display stock indicators** (`9`) — Menu placeholder for viewing metrics[cite: 1].
10. **List critical stock products** (`10`) — Menu placeholder for low-stock alerts[cite: 1].
0. **Exit system** (`0`) — Terminates the application loop[cite: 1].
